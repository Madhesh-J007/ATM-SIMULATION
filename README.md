# ATM Simulation using C++

A console-based ATM simulation system developed using C++ using Object-Oriented Programming principles and file handling.

## Features
- Create new bank accounts
- 5-digit account number validation
- 4-digit PIN authentication
- Secure login with limited attempts
- Balance enquiry
- Deposit and withdrawal operations
- Minimum balance enforcement
- Delete account functionality
- Persistent data storage using files

## Technologies Used
- C++
- Object-Oriented Programming (OOP)
- File Handling
- Standard Template Library (STL)

## How to Run
1. Compile the program:
   ```bash
   g++ main.cpp -o atm
2. Run the executable:
   ```bash
   ./atm

## Notes
- Account holder names should not contain spaces.
- Account data is stored locally using a text file (accounts.txt).
